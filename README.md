# MergeWar

一个约十分钟一局的单人酒馆构筑游戏原型，用于验证“招募—构筑—自动战斗”循环是否足以驱动用户连续开局。

当前版本是玩法研究原型，暂时使用现行酒馆战棋资料降低规则验证成本；它不是可公开发行或商业化的产品版本。Cloudflare 预览地址只用于受控试玩和验收。

## 当前范围

- 三名当前酒馆英雄：诺兹多姆、雷诺·杰克逊和伊利丹·怒风；
- 亡灵 21 张、龙 22 张，覆盖当前数据快照中的两个完整种族和六个等级；
- 额外中立随从、衍生物，以及适用于亡灵与龙环境的 46 张现行酒馆法术和 1 张衍生法术；
- 每次刷新额外出现一张法术，支持独立法术售价、生命值购买、抉择、发现、延迟结算、护甲和商店永久强化；
- 购买、出售、刷新、冻结、升本、三连和高一级发现；
- 嘲讽、圣盾、风怒、复生、烈毒、战吼、亡语、回合结束及战斗开始效果；
- 一名玩家和七名经营型电脑对手：各自保留金币、酒馆等级、升级费用、商店、手牌和阵容，并实际执行购买、出售、刷新、升本、三连与站位；
- 十回合上限、生命值、伤害和八人排名；
- 响应式操作页面与独立战斗页面，适配手机竖屏、手机横屏、桌面和刘海安全区，支持点击选牌、点击调整站位、鼠标和触摸拖动；
- 战斗回放支持攻击位移、碰撞闪光、浮动伤害、阵亡退场、召唤与复生入场，以及风怒气旋、嘲讽护卫框、复生灵魂符文等棋子属性特效；支持暂停、1×/2×/4×速度和战后关键原因；
- 游戏逻辑在浏览器运行，不需要登录；完成对局与主动反馈会匿名写入 Cloudflare D1。

## 运行

项目没有运行时第三方依赖。进入目录后运行：

```bash
npm run dev
```

然后打开 <http://localhost:4173>。

开发服务使用与线上一致的 Cloudflare Pages Functions 和本地 D1。首次运行会自动应用本地数据库迁移。如果只需要不带上传能力的 Node 版开发服务，可以运行 `npm run dev:node`，数据会写入未纳入版本控制的 `data/playtests.jsonl`。

## 试玩反馈接口

一局结束后，页面会自动把匿名游戏结果和结构化行为日志保存到 Cloudflare D1，即使测试者跳过反馈也能记录完成局数、时长、英雄、排名、战绩、最终阵容，以及购买、打出、出售、刷新、升级、站位和战斗回放等操作。随后测试者只需给本局打 1 至 5 分，也可以选填一条建议。系统不会主动收集姓名、联系方式、IP、持久设备标识或反馈输入过程。

```text
POST /api/playtests/complete  自动上传已完成对局
POST /api/playtests/feedback  为同一本局补充反馈
GET  /api/health              检查线上服务和存储类型
```

两个提交接口使用同一本局随机编号幂等写入，因此网络重试不会产生重复对局。行为日志以相对开局时间、回合、阶段、操作类型、卡牌 ID 和当时的金币/等级/手牌/场上数量保存，单局最多保留 300 条。线上数据保存在 Cloudflare D1 数据库 `mergewar-playtests` 的 `playtests` 表中，不开放公网导出接口。可使用 Wrangler 或 Cloudflare 控制台查询、导出和分析。

```bash
npm run db:migrate:remote  # 应用线上表结构迁移
npm run deploy             # 部署到 mergewar Pages 项目
```

例如，可使用 `npx wrangler d1 execute mergewar-playtests --remote --command="SELECT COUNT(*) FROM playtests"` 查看线上完成局数。

## 测试

```bash
npm test
npm run simulate
npm run build
```

`npm run simulate` 默认运行 300 局带种子的完整对局，用于检查崩溃、回合数、胜率与排名分布；`npm run build` 只把运行所需的静态文件写入 `dist/`。

## 素材来源与使用边界

- 名称、中文卡牌文本、属性和卡牌 ID 取自 2026-08-23 获取的 [HearthstoneJSON](https://hearthstonejson.com/) 最新 `zhCN/cards.json`；
- 页面通过 `art.hearthstonejson.com` 远程引用对应卡图，图片不保存在本仓库；
- 《炉石传说》及酒馆战棋相关名称、美术和游戏内容归 Blizzard Entertainment 所有；
- 当前版本只用于内部玩法研究和受控试玩，不应公开传播、商业化或提交微信小游戏审核；正式发行版需要替换名称、图片、文案、音频和足以构成实质性近似的表达。

当前原型故意不包含：

- 微信登录、分享和广告；
- 真人匹配、服务端同步及完整经营AI；
- 饰品、任务、双打、7级酒馆和亡灵/龙以外的种族专属卡池；
- 炉石音频、特效、边框及客户端 UI 的逐像素复刻。

七个电脑对手使用与玩家相同的基础经济约束，并按流派、对子、卡牌强度和阵容位置做启发式决策。玩家参与的战斗使用完整战斗规则，电脑之间暂时仍使用战力估算；后者是当前主要简化，而不是直接生成阵容。

## 下一步验证

1. 让 5 至 10 名熟悉酒馆战棋的测试者每人完成至少三局；
2. 记录首局完成率、中位单局时长和立即重开率；
3. 验证熟悉酒馆战棋的玩家能否快速理解压缩后的六级卡池；
4. 检查经营型电脑的决策是否可信，并记录明显错误的购买、升本和站位；
5. 核心循环成立后，再接入微信小游戏平台层。
